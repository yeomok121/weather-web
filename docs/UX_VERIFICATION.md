# 신뢰성·회원·모바일 산행 준비 검증

검증일: 2026-11-09 (Asia/Seoul)

## 구현한 요구사항

1. 조회 상태를 연결 중 / 지연 / 재시도 / 지난 자료 / 실패로 구분한다.
   실제 0은 유지하되 미수신 수치는 `—` 또는 `자료 없음`으로 표시한다.
   기상 자료가 없으면 활동 추천과 점수를 생성하지 않는다.
   같은 장소에서 받은 최근 1시간 이내 자료만 지난 자료라고 명시해 제공한다.
   실패한 조회는 연결 복구·탭 복귀·다시 확인으로 회복한다.
   쓰기 요청은 자동 재전송하지 않으며, 오래된 예보로 새 계획을 만들지 않는다.
2. 개인 계획, 초대, 파티 역할, 담당자, 준비 완료 상태를 서버에서 검증한다.
   개인 체크 상태는 파티를 만들 때도 유지한다. 파티는 30초마다 갱신하고
   새로고침 버튼으로 즉시 확인할 수 있다. 이름과 아이디만으로 비밀번호를
   바꿀 수 없도록 현재 비밀번호 검증을 적용했다.
3. 산 선택 → 출발 시간 비교 → 계획 저장 → 일행 초대·물품 분담을 연결한다.
   비회원의 작성 중 체크리스트를 로그인 후 이어받는다.
   계정별 초안과 마지막 파티를 복원하고 출발 시각을 절대 날짜로 저장한다.
   공유 링크는 로그인·파티 접근 검증을 거치며 접근 권한을 부여하지 않는다.

파티 연결 차단, 다른 사람 초대 수락 차단, 일반 구성원의 초대·파티 삭제 차단,
빈 물품·중복 물품·빈 변경 요청 거절을 포함한다.
