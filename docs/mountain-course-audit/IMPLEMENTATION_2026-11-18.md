## 반영 범위

- 기존 20개 산의 28개 코스: 이름·순서·기존 거리·시간은 유지. 11월 11일 대조 결과와 공식 링크를 표시하며 검증 완료로 승격하지 않음.

- 현장 검증·현재 입산 가능 여부 검증을 의미하지 않음.

- 삼악산: 춘천도시공사 B코스 전체 종주 수치. 복귀 교통편 별도.

- 장안산: 기관 편도 거리와 시간을 각각 2배로 환산. 하산 소요시간은 공식 값이 아닌 서비스 추정.
- 공식 난이도가 없는 코스는 미제공. 점수·열량·정상 도착 시각 계산은 기존 서비스 추정이며 출처 검증 범위에 포함하지 않음.

## 자료 관리

앱 데이터: `src/pages/mountain/data/courseSources.json`. 모든 변경은 출처 URL·대조일·경로·편도/왕복 기준을 함께 기록한다. 기존 목록 인덱스는 저장 일정 호환성 때문에 변경하지 않는다.
서버 목록의 `course_available: false`가 프런트의 보강 코스를 덮어쓰지 않도록 병합한다. 이 커밋은 서버 API의 코스 데이터 자체를 변경하지 않는다.
숲나들e 이전 상세 링크에서 404가 확인되어, 추가 산의 경로 참고는 산림청 공식 PDF로 연결했다. PDF의 `#page`는 인쇄 쪽수가 아닌 PDF 뷰어 페이지다.
