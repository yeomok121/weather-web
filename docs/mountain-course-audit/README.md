# 산악 코스 데이터 조사 · 1, 2단계

확인일: 2026-11-11

## 산출물

- `MOUNTAIN_50_SOURCES.md` / `mountain-50-source-plan.json`: 실제 앱 목록의 50개 산별 기관 출처·대표 코스 후보·남은 조사 사항.
- `EXISTING_20_AUDIT.md` / `existing-20-audit.json`: 기존 20개 산의 등록 코스 28건을 개별 대조한 결과.
- `registered-snapshot.json`: 대조 시점의 프론트엔드 등록값. 앱 실행 시 읽는 데이터가 아님.
- `official-course-index.json`: 국립공원공단 공개 코스 목록 조회 결과. 상세 페이지 식별용이며 정식 API 제공·이용허락을 뜻하지 않음.
- `source-extracts.json`: 공식 상세 페이지의 짧은 수치 근거. 이미지에만 있는 값은 추측하지 않음.
- `validate.py`: 문서/JSON의 산 개수, 기존 코스 누락, 링크 형식, 미승인 상태를 확인하는 자료 검사.

## 결과를 해석하는 기준

공식 웹사이트에 실린 코스라는 것과 현재 앱 코스가 정확히 그 경로라는 것은 다릅니다. 같은 산·정상이라도 들머리, 경유지, 하산 지점과 편도/왕복이 다르면 거리·시간을 직접 비교할 수 없습니다. 현재 모든 코스는 자동 반영 승인 보류입니다. 표에서 수치가 일치해도 난이도 전체, 현재 개방 여부, 현장 상황까지 검증되었다는 뜻이 아닙니다.

기존 28개 코스 모두 대조 기록을 작성했습니다. 확인된 동일 왕복 수치 일치는 오색과 중산리이며, 백무동 시간과 오대산 거리는 차이가 확인됐습니다. 다른 코스는 근거 범위나 경로를 추가 확인해야 합니다.

추가 30개 산은 자료 조사표를 작성했지만 모든 산의 채택 가능한 상세 코스를 확보한 것은 아닙니다. 공식 자료 후보를 찾은 산도 현재 운영 여부·왕복 기준을 확인해야 합니다. 상세 원문을 못 찾은 항목은 명시적으로 남겼으며 블로그나 임의 산식으로 채우지 않았습니다. 숲나들e의 오래된 교통·소요시간 안내는 최신 운영 근거로 사용하지 않습니다.

## 다음 데이터 반영 단계의 승인 조건

1. 산·정상 식별, 들머리 좌표, 도착점, 경유지, 왕복/편도/순환 확정.
2. 거리와 시간은 각각 원문 URL·기관·확인일·기준 구간 기록. 구간 합산은 원문 총계와 구별.
3. 운송(곤돌라/버스), 휴식 포함 여부, 공식 난이도 체계와 앱 등급 대응 확인.
4. 공식 페이지 내부 숫자가 충돌하거나 경로가 불명확하면 승인 보류하고 관할 관리기관에 확인.
5. 개방 여부·예약·입산/하산 통제는 고정 코스 정보와 별도로 최신 공식 공지 확인.
6. 승인된 데이터만 별도 변경으로 앱에 반영하고 산행 계산에 미치는 영향을 검증.

이번 커밋은 조사 문서만 추가합니다. 프론트엔드 코스, 백엔드 목록, 예보·점수·회원·파티 로직은 변경하지 않았습니다. 앱 기능 테스트 및 현장 검증은 실시하지 않았습니다.
