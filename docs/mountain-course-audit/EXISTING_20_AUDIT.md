## 변경 우선순위

1. 백무동: 같은 왕복 경로에서 570분과 공식 660분 차이 확인. 다음 데이터 수정 단계에서 근거를 붙여 변경.
2. 오대산: 7km와 공식 왕복 6.8km 차이. 시간 210분은 공식 190~210분 범위에 포함.
3. 나머지: 출발·도착·경유·회귀 경로부터 확정. 편도 시간 두 배로 왕복 시간을 임의 생성하지 않음.
4. 난이도는 공식 구간별 등급과 앱의 중상/최상 등이 같은 체계인지 확인해야 함. 수치 일치만으로 전체 코스 검증 완료 처리 금지.

산행 시간 계산, 속도 계수, 정상 도착 비율, 일몰 기반 하산 권장값의 타당성은 이 조사에서 검증하지 않았습니다.
